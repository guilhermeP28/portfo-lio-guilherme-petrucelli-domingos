### 👨‍💻 Sobre
Sou almoxarife com mais de 3 anos de experiência em controle de estoque, conferência de notas fiscais e organização de recebimento de materiais. Venho migrando minha trajetória para a área de Tecnologia da Informação ao perceber, na prática, como sistemas bem construídos facilitam processos que antes eram manuais. Atualmente curso **Análise e Desenvolvimento de Sistemas** na UNICID e aplico esse conhecimento técnico no desenvolvimento de soluções e automação de processos.

* **Foco Atual:** Desenvolvimento com Python, lógica de programação e administração de banco de dados aplicados a cenários reais.
* **Habilidades Técnicas:** Python, Desenvolvimento Web (HTML, CSS e JavaScript), Administração de Banco de Dados e Modelagem de Fluxogramas.
* **Diferencial:** Experiência prática em conferência de notas fiscais e organização de materiais, o que me permite criar softwares de logística que realmente atendem às necessidades do setor.
